# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| `2.0.x` | Yes |
| `< 2.0` | No |

## Reporting a Vulnerability

Please report security issues via GitHub Security Advisories on [`aryanhood/hawkeye-lite`](https://github.com/aryanhood/hawkeye-lite/security). Do not open public issues for undisclosed vulnerabilities.

## Scope & Safety Boundary

`hawkeye-lite` is an offline monocular and multi-angle sports computer vision pipeline (`Video Input -> Video Output`). It executes locally with zero external network calls during inference or benchmarking.
